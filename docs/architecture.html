AI-driven chaos engineering for cloud-native resilience

ChaosPilot AI: agent architecture

Five agents run as nodes in a LangGraph state graph. Each one asks Gemini for its decision and acts through its own tools. Trusted code sits between the agents and the cluster.

What each agent decides

AgentDecisionReads
ObserverWhether the shop is healthy enough to test, and which services already look unhealthyProbes, deployments, pods, restarts, warning events, logs
PlannerA ranked list of experiments, and which one runs nextDependency map, the Observer's report, earlier results
InjectorWhether to inject now, for how long, and whether to roll back earlyPre-flight probes, live readings during the fault, safety limits
AnalystWhat the failure revealed, its severity, and the fixesBefore, during, recovery and after measurements; cluster state during the fault
ReporterThe ranking of all weaknesses by severity, and what the score meansEvery experiment's result, score and diagnosis

Fixed in code, never decided by the model: the three allowed failure types, the protected services, the duration limits, the automatic abort and the resilience score formula.
